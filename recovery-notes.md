# Заметки о восстановлении

- Что восстановлено из истории Git: удалённый абзац с допущениями (через `git restore`).
- Что восстановлено из резервной копии: (заполню позже в Части 7).
- Использованные команды: `git diff`, `git restore`, `git show HEAD~1:Budget.md`.

## Сравнение способов восстановления

- Из истории Git: восстановлен удаленный абзац (через git restore).
- Из резервной копии: вся папка целиком, включая настройки и файлы.
- Вывод: Git не заменяет резервную копию; копия защищает то, что еще не попало в историю.
